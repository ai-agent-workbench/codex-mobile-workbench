# 与旧公开项目的关系、差异和兼容边界

本项目延续“用手机操作自己电脑上的 AI 工作台”的目标，但采用新的 Codex 原生执行链和独立实例工具。旧项目保留为 [AI Agent Workbench 历史仓库](https://github.com/ai-agent-workbench/ai-agent-workbench)，不删除或改写其历史；新建仓库不表示重新取得或清除代码、素材和依赖的版权。

## 哪些发生了变化

| 维度 | 旧公开仓库 | 本项目 |
|---|---|---|
| 执行后端 | Codex CLI／Kimi CLI 适配 | 固定版本 Codex App Server 原生 Thread／Turn |
| 任务交互 | 旧任务生命周期与自建接线 | Conversation Service／Runtime、原生交互与受管成果 |
| 权限与认证 | 旧网关、TOTP、Windows PIN／桥等设计 | 手机 Passkey／会话与原生权限／审批各自负责，不沿用旧 PIN 作为第二层执行裁判 |
| 安装和运维 | 按作者环境手工配置的参考实现 | Windows 薄面板和 WSL 独立实例，明确软件、状态、workspace 与原生 HOME 边界 |
| 对外范围 | 多后端架构与协作方法参考 | Windows／Ubuntu WSL 上本人使用的 Codex 手机入口技术预览 |

旧仓说明中的 Kimi、旧 Windows 桥、业务路由和网关配置，不因名称或部分代码相似而成为本项目支持的能力。DOT／旧 Web Push 等保留源码也不自动进入预览支持范围。

## 安装而不是原地覆盖

- 本项目未提供、未验收从旧公开仓库的原地升级或数据导入工具。不要把新软件覆盖进旧目录、指向旧数据库或复制旧认证配置／原生登录缓存。
- 新建独立实例，使用自己的账号与 HTTPS 接线；新旧实例可以分开保留，但必须核对目录、服务、端口和手机来源，不让新入口接管旧资料。
- 本项目自身的实例备份／恢复，只覆盖它明确声明的对象，不是旧仓迁移、跨系统镜像或任意原生历史恢复的保证。
- 即使保留旧版代码，回退程序也不等于回退数据。任何未来迁移须另行盘点对象、兼容格式、停写和一致备份，并真实验收后才能承诺。

## 已验证与未验证

维护者已在原宿主的新独立实例完成原生登录、受信 HTTPS、实体手机绑定、真实模型任务和成果下载内容确认，维护重启后原对话保留并能继续。另一台电脑、原生 Linux、完整切后台／断网返回和旧公开版导入均不在本次已验收范围；见 [支持矩阵](SUPPORT_MATRIX.md)。

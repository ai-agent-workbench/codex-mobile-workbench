## 已有核验与范围

维护者在本项目的新独立实例中完成了固定 0.160.0 完整原生运行包、无 `.git` 同包源码的实际安装及后续同项目维护升级，并完成相关回归和独立检查；这不包含旧公开 CLI／Kimi 仓库的升级。手机核心任务与文件下载由本人确认。完整包的精确源码清单和面板校验值位于 `package-source.json`，公开附件的 SHA-256 以对应 Release 为准。默认分支或源码归档不自动等于已发布安装包。

preview.2 的受检实现为 `7b07632`：1424 项回归、真实 curl／pip 的直连／代理失败不换路场景，以及同宿主含中文、空格、括号和单引号的新目录完整包安装／核验／保留资料卸载通过。preview.2 最终发行仅更新三份说明文档，实现、依赖和 Windows 面板字节保持一致，复用适用验证，不重复宣称已在全新物理机运行。Windows 面板编译、自测与控件事件检查通过；本机桌面截图全黑，不能据此记作 preview.2 视觉验收通过。

实机上传合成资料、完整切后台／断网返回、另一台电脑首次安装和原生 Linux 均未在本次验收中完整覆盖。安装／恢复的隔离行为检查、原宿主工程记录、真实手机核心闭环是不同证据，不互相替代；具体关系见 [兼容说明](LEGACY_COMPATIBILITY.md)。不凭测试数量判断安全，也不把其他版本的结果说成当前通过。

## preview.3 的核验边界

本版新增首次权限选择、公开 CI、依赖内容哈希强制校验及已知漏洞依赖更新。权限／迁移／恢复、离线浏览器和依赖安装分别验证，远程 CI 的实际状态见仓库 Actions。没有重新声称完成另一台电脑或实体手机的新一轮验收；2026-10-28 的真实手机记录仅是明确版本的历史证据。新建 v2 profile 不得回退到不认识该格式的旧控制器；已有 v1 profile 保留原兼容路径。

## preview.4 的核验边界

恢复摘要、旧 v1 恢复点兼容及新 v2 时间字段有回归检查。Windows 面板在两种窗口尺寸检查范围说明可见性，并以可滚动详情显示完整结果。隔离浏览器演练使用同一实例数据，经真实认证、对话／运行时和恢复 API 验证同根 Web 重启后重连、新根恢复后旧登录拒绝、重新注册后文件内容一致，以及两个未知投递命令不被重放；原始成功任务仅发送一次。完整原生运行包的体积与供应链在此演练使用微型合成固定材料，不冒称真实模型执行。实际公开 CI 状态以对应提交为准。

未执行影响日常环境的 WSL 整机重启；没有另一台物理电脑的新安装或恢复验收。CDP 冻结／恢复和离线状态只是浏览器模拟，不能替代真实手机操作系统挂起及恢复。既有实体手机记录仍明确归属于其历史版本。

## 已知限制

- 电脑休眠、WSL／网关重启、路由器／宽带入站和上游故障无法靠页面重连一概解决。
- 源码包是联网安装入口，不携带 `.venv`、Python wheels、Codex 程序、模型或生产服务配置。
- 核心运行依赖已采用版本与 wheel 内容哈希锁，安装强制校验；支持范围为 CPython 3.12／Linux x86_64。历史可选 Web Push 的 http-ece 仍采用哈希锁定的源码包与独立构建依赖；不因此纳入正式功能支持。内容哈希不能被描述为可重现构建或代码签名证明。
- 原生版本之间的协议摘录用于适配／回归，不代表这些所有版本都在公开预览支持范围。
- Windows EXE 未签名；须核对 Release 来源和同包校验，不承诺代码签名或组织策略兼容性，也不要求关闭系统保护。

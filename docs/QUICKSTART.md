# 第一次安装和使用

[简体中文](QUICKSTART.md) · [English](QUICKSTART.en.md)

装好后，你可以用手机派任务，让自己的电脑执行，再把成果拿回手机。

## 开始前

- 电脑需要 Windows＋Ubuntu 24.04 WSL2（x86-64、Python 3.12）。其他必需组件见[安装环境](../INSTALL.md#安装环境)。还没安装 WSL，可先按[微软安装说明](https://learn.microsoft.com/windows/wsl/install)准备 Ubuntu 24.04，再继续本页。
- 准备自己的 Codex 账号，以及可访问软件下载和模型服务的网络。代理不是一律必需。
- 手机最终需要一个稳定的 HTTPS 网址，**没有网址也可以先完成下面第 1–5 步的软件安装和登录**。到第 6 步再按[手机网址怎么准备](PHONE_ACCESS.md)接线，不需要先部署域名或通道才能安装。

## 1. 下载和安装

1. 在 [Releases](https://github.com/ai-agent-workbench/codex-mobile-workbench/releases) 下载完整 Windows／WSL 安装包。不要选自动生成的 `Source code` 压缩包，它没有面板 EXE 和安装清单。
2. 完整解压，双击 `CodexWorkbenchPanel.exe`，选择自己的 Ubuntu，点“运行检查”。如果系统拦截程序，先核对下载来源和系统策略，不要关闭保护来强行运行。
3. 在自己的 WSL 主目录下选一个新目录，点“安装准备”。不要覆盖已有工作台或资料。
4. 选择联网方式：沿用现有 WSL 配置、明确直连或指定代理。保存后点“安装”，等待完成。**安装完成不等于已经启动。**

## 2. 登录并启动

5. 点“原生账号登录”，在弹出的终端和浏览器中完成自己的 Codex 登录，再点“运行检查”。不要把设备码或登录凭据发给别人。
6. 记下运行检查结果的“本机地址”，按[手机网址说明](PHONE_ACCESS.md)把这个 WSL 回环地址接到过滤网关，再取得稳定 HTTPS 网址。在“手机 HTTPS 入口”填入网址、保存，点“启动”。通道刚创建但工作台尚未启动时出现 502，不等于需要重装。

## 3. 用手机打开

7. 用手机扫描普通访问二维码，或直接打开保存的网址。应看到自己工作台的登录页，没有证书警告。打不开时先检查电脑服务和连接方式，不要反复重新登录 Codex。
8. 在电脑面板点“绑定手机”，在自己的手机上按提示完成验证。一次性口令10分钟后失效，不要分享。

## 4. 做第一个任务

9. 在手机工作台首次新建对话前，明确选择只读、工作区可写（推荐）或完全访问；这只决定以后新对话的默认权限，仍受操作系统与原生审批边界约束。然后新建一个空的测试项目和对话，看一下所选模型和权限。发送下面这段话，不需要先上传资料：

```text
只生成一个名为“首次使用.txt”的文件，内容为“这是我的第一份成果”。请将文件交付到本对话，提供可点击的下载入口，不要只回复文件路径；不要改动其他文件。
```

10. 你在手机上点开文件，核对文件名和内容。**能取得这份正确的文件，就完成了首次使用。**

电脑和 WSL 需要保持运行。关闭面板不会停止后台任务；停止、备份和恢复见[维护说明](OPERATIONS.md)。

遇到问题时记下卡住的步骤和提示，再看[排错说明](TROUBLESHOOTING.md)；不要反复发送状态不明的同一任务，也不要上传密码、绑定口令或完整私有日志。

定时任务、完成通知默认关闭，按需要启用即可。锁屏、切网、断网恢复等测试不必在第一次使用时一起做。

用过旧公开版的用户请先看[兼容说明](LEGACY_COMPATIBILITY.md)，不要覆盖旧目录。

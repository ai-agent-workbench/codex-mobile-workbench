# 启停、升级与恢复

## 日常运行

电脑需要开机，WSL 与相应用户服务需要可运行，手机需要自己的可达 HTTPS。退出面板不代表停止任务；电脑休眠、账号退出、网关或上游不可达都可能造成中断，不能只看首页能打开。

在面板“安全停止／重启”前核对在途任务。忙碌或状态未知时不能强停；不要裸杀进程、重启另一实例或用关闭认证来排障。

## 部署开关

- 新实例 `CODEX_WEB_AUTOMATIONS_ENABLED=0`、`CODEX_WEB_COMPLETION_NOTIFICATIONS_ENABLED=0`。设置影响实际服务进程，保存后按安全流程重启，不是网页偏好。
- 停用定时不删除既有记录，重新启用不补跑错过的时段；已经接受的命令仍按原授权核对。启用后，任务继续在手机对话中管理。
- 完成通知只使用实例所有者自己的任务发送器和私密主题文件路径；不要填主题正文、复制他人配置或借安全告警通道兜底。未配置不做发送测试；结果未知不自动重发。
- 源码保留的 DOT、旧 Web Push 等实现不是本次预览支持承诺；默认独立实例不启用 DOT，也不要为“试一下”导入个人集成凭据。

## 备份到底包含什么

先安全停止，再在面板备份。范围是该实例的配置、`state` 白名单资料（不是整个目录）、实例 `workspace/`、当前及最多一个健康回退程序、控制器和原生程序包；**不包括整台电脑、外部项目目录、原生登录缓存、其他历史程序版本或主机实际网关／组网环境，也不保证覆盖全部原生历史**。外部目录必须另行备份并核验。

备份有认证数据库和私人文件，权限必须只给本人；不要当作安装包、示例或故障附件分享。运行中的 SQLite／WAL 不能用随手复制文件冒充一致备份。

面板显示恢复点捕获 UTC 时间、实际资料文件／数据库／字节数及程序版本数；资料校验和程序是否需要重建分开显示。范围和敏感性提示在备份前可见。新备份使用带时间字段的 v2 清单：新版仍能校验和恢复 v1，旧备份时间显示“未知”，不从目录名或文件时间猜测；旧控制器不认识 v2，使用生成备份的新版本或兼容的新版本恢复，不手改格式降级。时间记录不是跨数据库原子快照证明，仍要求先安全停止写入。

## 恢复到新目录

填写所选备份和新目录后，面板先只读核验恢复点并展示摘要，确认后才写入新目录。命令行可通过 `inspect-backup` 动作及标准输入 `{"backup":"/绝对备份路径"}` 执行同一预检；不要求选中目录已有实例，不创建恢复目标。实际恢复仍重新校验，预检成功不代替写入前校验。

- 在满足环境条件的新目录恢复，不覆盖旧实例；不自动启动、不移植原生登录、不重放任务。本人需重新登录并核对账号、项目路径和手机接线。
- 同环境可恢复带回的健康程序和回退版本。可信系统 Python 基座字节变化时仅恢复已校验资料，再重建当前软件；不是把旧 venv 当跨机器镜像运行。
- 已有工程证据包括同宿主模拟基座变化，**不是原生 Linux 迁移、任意操作系统／架构或整机灾备验收**。
- 外部 cwd、原生历史和送达待核对状态须逐项核对；不能因恢复出来文件可读就宣称任务能自动续跑。

完成结果显示恢复时间、附件重绑数量、未物化的外部工作目录数和最终数据库中投递未知的命令数。程序需重建时先安装，再由本人完成原生登录、重新配置 HTTPS／绑定手机，检查工程和计划；不是恢复成功就自动具备登录或联网能力。后续状态刷新失败仍保留本次已完成操作的摘要，不能因此重复恢复到同一路径。

## 升级、失败和卸载

本节只适用于本项目创建的独立实例，**不是旧公开 CLI／Kimi 工作台的升级或迁移流程**；见 [兼容说明](LEGACY_COMPATIBILITY.md)。

先安全停止并核验空闲，再做一致备份，再使用匹配的同包软件安装／启动。核心控制器验证候选，失败时按其已验证回退链处理；回退切换程序，**不会自动撤销数据库变化**。不认识新数据格式的旧版不能盲目启动。

“卸载入口（保留资料）”注销该实例服务与运行入口，保留资料和备份，并保留旧程序；不等于清盘。删除用户资料需明确对象和恢复影响，不把卸载授权扩大为删除外部项目。

### 隔离恢复故障演练（维护检查）

在源码工作树中运行：

```bash
CODEX_WEB_PYTHON=/path/to/isolated-venv/bin/python \
NODE_PATH=/path/to/node_modules PLAYWRIGHT_BROWSERS_PATH=/path/to/playwright \
python3 scripts/run_ui_checks.py recovery
```

该检查仅创建任务私有临时实例目录、TLS、临时 WebAuthn 资料、回环 TCP 和私有 UDS 子进程；使用同一隔离实例的真实 Passkey 路由、`CodexAppServerClient` 协议连接、生产对话页面/脚本、真实 artifact 发布/下载及 `instance_recovery.backup/restore` API。它先验证同根 Web 进程停止／启动后原页面通过 WebSocket 重连、草稿保留及文件下载，再停止 Web 子进程，对浏览器实际使用的 state/workspace 备份并恢复到新根目录，验证两个未决命令变为未知投递、旧会话与凭据撤销、重新注册后从恢复根目录下载文件并且不会重复 `turn/start`。合成 UDS 服务只实现此演练所需 RPC，绝不调用模型或命令。

边界：这不是实体手机、WSL 整机、生产 systemd/网关或真实 Codex 历史迁移验收；浏览器的后台切换通过 CDP 冻结／恢复生命周期及浏览器离线状态 模拟，不能证明移动操作系统实际挂起行为。临时进程只由检查本身按 PID 终止。

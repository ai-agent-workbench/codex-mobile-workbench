# 启停、升级与恢复

## 日常运行

电脑需要开机，WSL 与相应用户服务需要可运行，手机需要自己的可达 HTTPS。退出面板不代表停止任务；电脑休眠、账号退出、网关或上游不可达都可能造成中断，不能只看首页能打开。

在面板“安全停止／重启”前核对在途任务。忙碌或状态未知时不能强停；不要裸杀进程、重启另一实例或用关闭认证来排障。

## 部署开关

- 新实例 `CODEX_WEB_AUTOMATIONS_ENABLED=0`、`CODEX_WEB_COMPLETION_NOTIFICATIONS_ENABLED=0`。设置影响实际服务进程，保存后按安全流程重启，不是网页偏好。
- 停用定时不删除既有记录，重新启用不补跑错过的时段；已经接受的命令仍按原授权核对。启用后，任务继续在手机对话中管理。
- 完成通知只使用实例所有者自己的任务发送器和私密主题文件路径；不要填主题正文、复制他人配置或借安全告警通道兜底。未配置不做发送测试；结果未知不自动重发。
- 源码保留的 DOT、旧 Web Push 等实现不是本次预览支持承诺；默认独立实例不启用 DOT，也不要为“试一下”导入个人集成凭据。

## 备份到底包含什么

先安全停止，再在面板备份。范围是该实例状态、实例 `workspace/` 与可用的固定程序／回退版本；**不包括整台电脑、外部项目目录或原生登录缓存，也不保证覆盖全部原生历史**。外部目录必须另行备份并核验。

备份有认证数据库和私人文件，权限必须只给本人；不要当作安装包、示例或故障附件分享。运行中的 SQLite／WAL 不能用随手复制文件冒充一致备份。

## 恢复到新目录

- 在满足环境条件的新目录恢复，不覆盖旧实例；不自动启动、不移植原生登录、不重放任务。本人需重新登录并核对账号、项目路径和手机接线。
- 同环境可恢复带回的健康程序和回退版本。可信系统 Python 基座字节变化时仅恢复已校验资料，再重建当前软件；不是把旧 venv 当跨机器镜像运行。
- 已有工程证据包括同宿主模拟基座变化，**不是原生 Linux 迁移、任意操作系统／架构或整机灾备验收**。
- 外部 cwd、原生历史和送达待核对状态须逐项核对；不能因恢复出来文件可读就宣称任务能自动续跑。

## 升级、失败和卸载

本节只适用于本项目创建的独立实例，**不是旧公开 CLI／Kimi 工作台的升级或迁移流程**；见 [兼容说明](LEGACY_COMPATIBILITY.md)。

先安全停止并核验空闲，再做一致备份，再使用匹配的同包软件安装／启动。核心控制器验证候选，失败时按其已验证回退链处理；回退切换程序，**不会自动撤销数据库变化**。不认识新数据格式的旧版不能盲目启动。

“卸载入口（保留资料）”注销该实例服务与运行入口，保留资料和备份，并保留旧程序；不等于清盘。删除用户资料需明确对象和恢复影响，不把卸载授权扩大为删除外部项目。

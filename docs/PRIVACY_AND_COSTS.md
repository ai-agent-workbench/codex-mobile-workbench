# 数据去向、外部连接和费用

## 保存在本机的内容

独立实例分别保存配置、软件、Web 对话投影数据库、上传、Artifact、workspace、原生 HOME、诊断与认证状态。路径由实例配置决定，不应写在源码里。诊断可能含时间、请求／轮次标识和经过限制的故障信息；日志／故障报告仍应作为私人资料，不要默认公开。

用户选择的外部项目目录和原生会话状态不自动变成实例备份覆盖范围。实例备份包含认证数据库和私人资料，虽不携带原生登录缓存，也不是可公开分享的匿名包。

## 哪些情况会联网

| 场景 | 去向／原因 | 默认说明 |
|---|---|---|
| 首次安装 | GitHub 官方 Codex 发布资产；PyPI Python 包 | 联网安装，使用本人已有网络配置；失败不冒充成功 |
| 本人登录／执行任务 | 原生 Codex 及本人选择的上游服务 | 用户提问、上下文、工具结果可能成为模型输入，不要当纯本地推理 |
| 模型按任务使用工具 | 由本人权限与任务决定的目标 | 不能承诺所有网络请求都只去 OpenAI |
| 手机入口 | 本人配置的 HTTPS 代理／私有组网 | 入口提供者可能见到必要连接元数据；是否终止 TLS 由实际部署决定 |
| 外部完成通知 | 本人配置的发送器／通知服务 | 新实例默认停用；启用后可见标题／完成内容等信息须按实际代码理解 |

本候选不新增集中遥测或自动将诊断发给作者；这不代表上游软件、用户自行启用的集成或模型执行任务完全不联网。代理配置可能含认证信息，服务环境文件不得随发行包或 Issue 分享。

# 排障：先确认卡在哪一层

| 现象 | 先检查 | 不要做 |
|---|---|---|
| 面板打不开 | 是否完整解压、来源／校验与系统策略；必要时按源码构建说明复现 | 关闭 SmartScreen／绕过执行策略、下载来路不明的 exe |
| 环境检查失败 | 选中的 WSL 发行版、Python3.12 venv、Git／curl、用户 systemd、本人网络 | 把作者目录、代理地址或凭据照抄过去 |
| 安装下载失败 | 区分依赖下载 `dependency_download_failed` 与原生程序下载 `native_download_failed`；核对已保存的联网方式。沿用读取 WSL 进程环境，指定代理需 WSL 实际可达；依赖和原生包是不同上游 | 以为必须装代理、把 Windows 浏览器能上网当作 WSL 一定可达、无控制地直连兜底、复制生产 venv |
| 原生未登录 | 在该实例的原生登录终端由本人处理；不要误在另一个 HOME 登录 | 发设备码／Token截图、搬运另一实例缓存 |
| 登录正常但任务连接失败 | 下载、账号登录、模型实际返回分别核对；普通检查只查询本地登录状态，不进行付费模型测试 | 把“已登录”或代理变量存在当作模型已连接、盲目重发投递结果未知的任务 |
| 电脑就绪但手机打不开 | 手机是否访问正确独立 HTTPS，证书／DNS／反代／WebSocket 与电脑休眠状态 | 把本机200当外网正常，自动改现有网关／防火墙或增加暴露 |
| 手机登录／绑定失败 | 原 HTTPS 来源、Passkey能力、一次性授权是否过期、是否在正确实例 | 发永久权限二维码，关闭认证绕过问题 |
| 页面断线但任务不明 | 返回原会话核对真实状态；区别传输中断、原生审批、模型运行和未知投递 | 重发未知命令、把刷新当重新执行授权 |
| 成果看不到／下不了 | 项目和会话归属、原任务终态、受管文件是否可读，下载是否被手机拦截 | 仅因服务端有文件就认为用户已取得，跨会话开放资料 |
| 备份／恢复被拒 | 是否安全停止、目标为空、文件完整性／链接／环境兼容错误 | 强行覆盖、忽略缺失对象或把原生登录随备份搬走 |

反馈时只提供：系统及固定程序版本、失败步骤、脱敏错误码／报告 ID、可公开的最小复现。不要附完整配置、备份、Cookie、账号信息或私人项目。维护者可能要求按范围补充证据，但不会以“排障”为由要求分享登录秘密。

# 怎样取得手机访问网址

[简体中文](PHONE_ACCESS.md) · [English](PHONE_ACCESS.en.md)

手机通过 HTTPS 网址访问你电脑上的工作台。没有现成网址，可以通过下面两种办法来准备。

先按[快速开始](QUICKSTART.md)完成电脑上的软件安装，再在面板点“运行检查”，记下显示的本机地址。**本机地址交给连接工具；连接工具给出的 HTTPS 网址，再填回工作台面板。**

## 方法一：电脑和手机装连接工具

以 [Tailscale Serve](https://tailscale.com/kb/1312/serve) 为例：

1. 在电脑和手机安装 Tailscale，用自己的同一账号登录，确认两台设备在线。
2. 在电脑按它的官方说明启用 HTTPS 访问，并按下方要求接入工作台的本机端口。
3. 复制 Tailscale 显示的 HTTPS 网址，填入工作台面板的“手机 HTTPS 入口”。

这种办法适合自己的设备之间使用，不需要为它另买域名；手机需要安装并保持连接客户端运行。

## 方法二：电脑接入托管服务，手机只用浏览器

以 [Cloudflare Tunnel](https://developers.cloudflare.com/tunnel/) 为例：

1. 准备自己的服务账号和可管理的域名。
2. 在电脑安装它的连接程序，创建通道，为工作台配置一个固定的 HTTPS 网址，并按下方要求接到本机服务。
3. 将这个网址填入工作台面板，手机用浏览器打开即可。

这种办法让手机少装一个应用，但需要准备域名并核对服务费用、隐私和访问设置。公网入口必须保留工作台本人登录。

以上是常见方法举例，不限定必须使用哪家服务。本项目已验证和未验证的范围见[支持说明](SUPPORT_MATRIX.md)。

## 网址准备好以后

完成自己的 Codex 登录，在面板保存网址，点“启动”。再用手机扫码或打开网址，看到正确登录页后，按[快速开始](QUICKSTART.md)绑定手机并完成第一个任务。

网址应保持稳定，便于以后继续登录。复制服务实际给出的地址，不要照抄文档示例或作者的地址。

## 入口配置要求

- 只转发工作台的本机端口，不公开原生 App Server 或 socket。
- 屏蔽 `/internal` 及其子路径，保留 WebSocket 和正确的 Host／HTTPS 信息。
- 使用独立的 HTTPS 域名；仅换路径或端口不能隔离 Cookie。保留本人认证，私有网络不代替工作台登录。
- 使用私有组网时，不要擅自切成公网模式或覆盖已有服务。绑定后换网址需按恢复流程处理。

Tailscale 的 HTTPS 设置还可参考[官方说明](https://tailscale.com/kb/1153/enabling-https)。启用前看清服务的隐私提示，设备名不要包含敏感信息。

## 打不开时先看什么

- 页面打不开：检查工作台是否已启动、连接程序是否在线；使用私有组网时，手机也要处于已连接状态。
- 有证书警告或进了其他网站：先修正网址与配置，再进行手机绑定。
- 页面能开但任务失败：分别检查手机绑定、Codex 登录和模型连接，不要反复发送状态不明的同一任务。

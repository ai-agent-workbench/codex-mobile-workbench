# 手机网址怎么准备

手机要靠一个网址访问电脑上的工作台。**这版软件不会自动生成这个网址。**

## 你已经有自己的网址

这里指你自己能够配置、准备用于本工作台的稳定 HTTPS 网址，不是随便找一个网站地址。

1. 在电脑面板点“运行检查”，记下本机端口。此时不必先启动。
2. 让自己的入口连接到这个端口，把 HTTPS 网址填回面板，保存后点“启动”。
3. 用手机扫码或打开网址，看到正确登录页后，再按[快速开始](QUICKSTART.md)完成手机绑定和第一个任务。

面板显示的 `http://127.0.0.1:端口` 是给电脑上的连接工具使用的，不是手机网址。不要把它、示例地址或作者的地址填成自己的手机入口。

## 你还没有手机网址

一般有两种办法：

| 办法 | 你需要做什么 |
|---|---|
| 私有组网 | 电脑和手机安装连接客户端，加入自己的网络，再使用该服务提供的 HTTPS 网址。手机通常要多装一个应用。 |
| 托管入口 | 电脑运行所选服务的连接工具，手机通常只用浏览器。固定网址、域名和费用按该服务的要求准备。 |

有些服务会分配稳定网址，因此不一定需要自己买域名或有公网 IP。选择前要确认访问范围、隐私和费用，不能一概承诺免费。

**这一步的具体操作教程还没补齐，目前也没有为本项目实测通过的推荐服务。** 没有网址的新用户，可能会卡在这里。

## 给负责配置入口的人

- 只转发本工作台的本机端口，不公开原生 App Server 或 socket。
- 必须屏蔽 `/internal` 及其子路径，保留 WebSocket 和正确的 Host／HTTPS 信息。
- 使用独立、稳定的 HTTPS 域名；仅换路径或端口不能隔离 Cookie。保留工作台本人登录，不因使用私有网络就取消认证。
- 私有组网不要擅自切成公网模式，也不要覆盖已有服务。绑定后别随意换网址，否则原来的手机登录可能失效。

可参考 [Tailscale Serve](https://tailscale.com/kb/1312/serve)、其 [HTTPS 说明](https://tailscale.com/kb/1153/enabling-https)，以及 [Cloudflare Tunnel](https://developers.cloudflare.com/tunnel/) 的官方资料。开启服务前应看清隐私提示；例如 HTTPS 证书可能公开设备域名，设备名不要包含敏感信息。

## 打不开时先看什么

- 页面打不开：先看本工作台是否已启动、连接工具是否在线，以及手机是否加入了所选私有网络。
- 有证书警告或进了别人的页面：停下来核对网址和配置，不要跳过保护继续绑定。
- 页面能开但任务失败：再分别检查手机绑定、Codex 登录和模型连接；页面能开不代表任务已经能执行。

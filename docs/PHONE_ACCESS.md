# 手机接入：先选路线，再验证真实可达

任务在自己的电脑上执行，手机继续操作、取得成果。普通家庭宽带不一定有可入站的公网地址；先比较下面两类路线，不要求开放路由器端口，也不默认绑定某个服务商。

| 路线 | 使用体验 | 需要核对的代价与边界 |
|---|---|---|
| 私有组网＋可信 HTTPS | 自己的设备之间访问；手机通常需安装并登录组网客户端 | 设备加入与访问规则、HTTPS 证书、直连失败后的中继、手机切网／省电行为、账号与套餐限制 |
| 托管 HTTPS 入口 | 手机通常只用浏览器；电脑连接器主动连出，适应无公网入站的家庭网络 | 固定域名与本人账号、第三方是否终止 TLS／可见哪些数据、流量与请求限制、费用、服务可用性和停用后的行为 |

私有网络不代替本人认证，HTTPS 也不等于访问控制。工作台是个人高权限工具，不是多人公共服务；两条路线都保留原生权限与工作台登录。

## 1. 准备固定、独立的来源地址

先把自己的实例运行起来，记录面板显示的回环端口。只把该端口通过所选入口转发；不转发原生 App Server，不公开 `/internal` 及其子路径，保留 WebSocket 和正确 Host／HTTPS 来源信息。

使用稳定、可信的独立 HTTPS hostname；同一 hostname 换路径或端口不能假装 Cookie 隔离。Passkey 绑定依赖来源，临时随机域名变化可能导致无法按原方式登录；已有绑定不能靠随意改 URL 自动迁移。

保存 URL 只记录配置，不安装客户端、不签证书、不修改网关／防火墙或创建隧道。已有组网、域名和入口保持，先用隔离实例验证。

## 2. 候选方案目前验证到了哪一步

2026-10-28 已通过受控代理核对以下官方资料；这些是代表候选，不是默认推荐或服务可用性承诺。

- [Tailscale Serve](https://tailscale.com/kb/1312/serve)：为 tailnet 内设备提供本地端口的 HTTPS 转发；需要相应 HTTPS 配置。**Serve 与公开 Funnel 不同**，不得为了手机接入静默启用 Funnel。尚未在新用户的电脑／手机上完成该候选的实际登录、切网与完整任务验收。
- [Cloudflare Tunnel](https://developers.cloudflare.com/tunnel/)：连接器主动连出，可把固定 hostname 指向本机服务；无需以开放家庭公网入站为前提，但流量经过第三方网络，须核对自己的域名、账号、TLS 和费用安排。尚未为本候选创建或验证真实托管入口。
- [Quick Tunnels](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)：官方定位为测试／开发用途，使用临时地址，有并发限制且不支持 SSE；不能因无需账号就把它作为长期绑定的默认方案。当前浏览器更新使用 WebSocket，仍需验证实际隧道，不能从协议名称推导稳定可用。

本机 TLS／代理的隔离测试不等于上述第三方链路实测；经维护者代理读到官方网页，也不证明普通家庭网络可直连该服务。未完成真实验证前不选默认供应商、不承诺免费或稳定可用。

## 3. 用手机完成验收，不靠电脑端绿灯

1. 在手机实际使用的 Wi-Fi 和蜂窝网络分别打开稳定 HTTPS 地址，确认正确实例、证书和登录页。
2. 完成本人的短期授权／Passkey 绑定；不要分享绑定口令、永久凭据或带权限的二维码。
3. 发起一个合成小任务，确认模型实际返回，打开并下载成果，核对内容。
4. 切后台／锁屏、Wi-Fi 与蜂窝切换、暂时断网后返回原对话，确认状态能核对，不自动重复执行未知任务。
5. 断开所选组网或托管连接器，确认访问失败被如实呈现；恢复后仍能登录原实例。停用或撤销入口的办法也应可理解。

这些步骤通过后再决定默认推荐路线和向导自动化范围。新入口、服务账号或访问范围改变应由实例所有者明确选择，不借测试接管已有网络。
